# Contributing to BoldoAtlas

**English** · [Español](CONTRIBUTING.es.md)

Thanks for your interest. You can write in English or Spanish.

## Report a bug or suggest an idea

Open an [issue](https://github.com/MscottB/BoldoAtlas/issues). In the app's **About** screen, the **Copy information** button prepares the version and technical details to paste. Do not include real data about people or your organization.

## Send code

1. For large changes, open an issue first so we avoid work that can't be merged.
2. Build and test with the commands in the development section of the [README](README.md). Before opening the PR, run `npm run test` and `cargo test --manifest-path src-tauri/Cargo.toml`.
3. Open the PR, fill in the template and tick the CLA acceptance box. Without it, the PR is not merged.
