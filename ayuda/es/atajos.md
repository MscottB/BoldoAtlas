# Atajos de teclado

Atajos propios de BoldoAtlas:

| Tecla                       | Qué hace                                                                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Ctrl` + `K`                | Abre la paleta de comandos: busca unidades, personas, puestos vacantes y acciones (funciona incluso escribiendo en un campo)                                  |
| `N`                         | Nueva unidad hija de la unidad seleccionada                                                                                                                   |
| `F`                         | Buscar en el lienzo                                                                                                                                           |
| `Supr`                      | Elimina lo seleccionado (hay 8 segundos para deshacer)                                                                                                        |
| `Esc`                       | Cierra el panel o el diálogo abierto                                                                                                                          |
| `Ctrl` + `0`                | Encuadra todo el árbol en la ventana                                                                                                                          |
| `←` `→` `↑` `↓`             | Recorren el árbol: `↑` va al superior, `↓` al primer hijo (abre la rama si está plegada), `←` `→` a los hermanos. Con el árbol en horizontal siguen el dibujo |
| `Ctrl` + `C` / `Ctrl` + `V` | Con un puesto enfocado en el árbol: copia o pega su estilo (leyenda)                                                                                          |

`N`, `F`, `Supr` y las flechas solo actúan en el árbol, cuando no estás escribiendo en un campo de texto ni hay un diálogo abierto. Viendo el organigrama a una fecha, `N` y `Supr` no hacen nada (es solo lectura). Con `Supr`, una unidad con contenido pide confirmación antes de eliminarse.
