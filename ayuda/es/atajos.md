# Atajos de teclado

Atajos propios de BoldoAtlas:

| Tecla                                     | Qué hace                                                                                                                                                      |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Ctrl` + `K`                              | Abre la paleta de comandos: busca unidades, personas, puestos vacantes y acciones (funciona incluso escribiendo en un campo)                                  |
| `N`                                       | Nueva unidad hija de la unidad seleccionada                                                                                                                   |
| `F`                                       | Buscar en el lienzo                                                                                                                                           |
| `Supr`                                    | Elimina lo seleccionado (hay 8 segundos para deshacer); con varias unidades seleccionadas, las elimina todas a la vez                                         |
| `Esc`                                     | Cierra el panel o el diálogo abierto; con varias unidades seleccionadas, quita la selección                                                                   |
| `Ctrl` + `0`                              | Encuadra todo el árbol en la ventana                                                                                                                          |
| `←` `→` `↑` `↓`                           | Recorren el árbol: `↑` va al superior, `↓` al primer hijo (abre la rama si está plegada), `←` `→` a los hermanos. Con el árbol en horizontal siguen el dibujo |
| `Mayús` + `←` `→` `↑` `↓`                 | Suman a la selección la unidad a la que iría la flecha (selección múltiple)                                                                                   |
| `Ctrl` + `D`                              | Duplica la rama de la unidad seleccionada; la copia queda a continuación de la original                                                                       |
| `Ctrl` + `C` / `Ctrl` + `V`               | Con un puesto enfocado en el árbol: copia o pega su estilo (leyenda)                                                                                          |
| `F2`                                      | Renombra la unidad enfocada o seleccionada                                                                                                                    |
| `Mayús` + `F10` / Menú                    | Abre el menú contextual de la tarjeta enfocada o seleccionada (o del fondo del lienzo, si no hay ninguna)                                                     |
| `Ctrl` + `T`                              | Abre una pestaña nueva en el árbol (funciona incluso escribiendo en un campo)                                                                                 |
| `Ctrl` + `W`                              | Cierra la pestaña activa (la última no se cierra)                                                                                                             |
| `Ctrl` + `Tab` / `Ctrl` + `Mayús` + `Tab` | Pasa a la pestaña siguiente o a la anterior                                                                                                                   |
| `Ctrl` + clic / clic central              | En una entrada del menú, un resultado de la paleta o una persona del Directorio: lo abre en una pestaña nueva                                                 |
| `Ctrl` + `Enter`                          | En la paleta de comandos: abre el resultado elegido en una pestaña nueva                                                                                      |

`N`, `F`, `Supr`, `Ctrl` + `D`, `F2`, `Mayús` + `F10` y las flechas (también con `Mayús`) solo actúan en el árbol, cuando no estás escribiendo en un campo de texto ni hay un diálogo abierto. Viendo el organigrama a una fecha, `N`, `Supr`, `Ctrl` + `D` y `F2` no hacen nada (es solo lectura) y tampoco hay selección múltiple. `Ctrl` + `D` solo duplica cuando hay una única unidad seleccionada. Con `Supr`, una unidad con contenido pide confirmación antes de eliminarse; varias unidades seleccionadas siempre la piden.

En la barra de pestañas (aparece desde la segunda): `←` `→` recorren las pestañas, `Enter` abre la enfocada, `Supr` la cierra y `Ctrl` + `Mayús` + `←` `→` la mueven. Más en la página «Pestañas de trabajo».
