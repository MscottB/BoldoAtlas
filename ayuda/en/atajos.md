# Keyboard shortcuts

BoldoAtlas's own shortcuts:

| Key                                       | What it does                                                                                                                                                           |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Ctrl` + `K`                              | Opens the command palette: search units, people, vacant positions and actions (works even while typing in a field)                                                     |
| `N`                                       | New child unit of the selected unit                                                                                                                                    |
| `F`                                       | Goes to the **Search the diagram** field in the canvas bar                                                                                                             |
| `Del`                                     | Deletes the selection (you have 8 seconds to undo); with several units selected, deletes them all at once                                                              |
| `Esc`                                     | Closes the open panel or dialog; with several units selected, clears the selection                                                                                     |
| `Ctrl` + `0`                              | Fits the whole tree in the window                                                                                                                                      |
| `←` `→` `↑` `↓`                           | Move around the tree: `↑` goes to the parent, `↓` to the first child (opens the branch if folded), `←` `→` to siblings. With a horizontal tree they follow the drawing |
| `Shift` + `←` `→` `↑` `↓`                 | Add to the selection the unit the arrow would go to (multiple selection)                                                                                               |
| `Ctrl` + `D`                              | Duplicates the branch of the selected unit; the copy goes right after the original                                                                                     |
| `Ctrl` + `C` / `Ctrl` + `V`               | With a position focused in the tree: copies or pastes its style (legend)                                                                                               |
| `F2`                                      | Renames the focused or selected unit                                                                                                                                   |
| `Shift` + `F10` or Menu key               | Opens the context menu of the focused or selected card (or of the canvas background, if there is none)                                                                 |
| `Ctrl` + `T`                              | Opens a new tab on the tree (works even while typing in a field)                                                                                                       |
| `Ctrl` + `W`                              | Closes the active tab (the last one can't be closed)                                                                                                                   |
| `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | Switches to the next or previous tab                                                                                                                                   |
| `Ctrl` + click / middle click             | On a menu entry, a palette result or a person in the Directory: opens it in a new tab                                                                                  |
| `Ctrl` + `Enter`                          | In the command palette: opens the chosen result in a new tab                                                                                                           |

`N`, `F`, `Del`, `Ctrl` + `D`, `F2`, `Shift` + `F10` and the arrow keys (also with `Shift`) only act on the tree, when you are not typing in a text field and no dialog is open. While viewing the chart at a past date, `N`, `Del`, `Ctrl` + `D` and `F2` do nothing (read-only) and there is no multiple selection. `Ctrl` + `D` only duplicates when exactly one unit is selected. With `Del`, a unit that has content asks for confirmation before it is deleted; several selected units always ask for it.

In the tab bar (shown from the second tab on): `←` `→` move between tabs, `Enter` opens the focused one, `Del` closes it and `Ctrl` + `Shift` + `←` `→` move it. More on the “Work tabs” page.
