# Keyboard shortcuts

BoldoAtlas's own shortcuts:

| Key                         | What it does                                                             |
| --------------------------- | ------------------------------------------------------------------------ |
| `Ctrl` + `K`                | Opens search (works even while typing in a field)                        |
| `N`                         | New child unit of the selected unit                                      |
| `F`                         | Search on the canvas                                                     |
| `Del`                       | Deletes the selection (you have 8 seconds to undo)                       |
| `Esc`                       | Closes the open panel or dialog                                          |
| `Ctrl` + `0`                | Fits the whole tree in the window                                        |
| `Ctrl` + `C` / `Ctrl` + `V` | With a position focused in the tree: copies or pastes its style (legend) |

`N`, `F` and `Del` only act when you are not typing in a text field.
